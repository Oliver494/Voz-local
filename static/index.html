Installation

Set up Voz Local on another computer. Choose your operating system.

What do I need?

The web needs a local server, Python, FFmpeg and a downloaded Qwen3-TTS voice model. Ollama is optional and only helps with writing.

The current installer is specific to Linux with the RX 9060 XT. A universal automatic installer is not available yet.

Download project ZIP

Includes the app and launchers. Python and the voice model download on the destination computer. Your voices and projects are not included.

Linux

Installer available

For the current Ubuntu + Radeon RX 9060 XT setup. Other GPUs and distributions need a different PyTorch setup.

  1. Download and extract the project

    Open a terminal in the extracted Voz Local folder. Keep it there: your voices and projects will be saved in its data folder.

  2. Run the installer

    bash instalar-e-iniciar.sh

    It prepares Python, FFmpeg, dependencies and the voice model, then opens the web.

  3. Start the web

    Use the same launcher next time. Completed dependencies and downloads are reused.

    Keep this terminal open while you use the app. Press Ctrl+C to stop the server.

    http://127.0.0.1:8765/ ↗

Windows

Installer available

Voz Local does not have a native Windows installer yet. The current Linux script is not a Windows installer.

  1. Download and extract the project

    Extract the whole project, including the scripts folder. The launcher cannot run by itself.

  2. Double-click the launcher

    Instalar e iniciar.bat

    It downloads a private Python 3.12 runtime if missing, installs FFmpeg using WinGet, prepares the dependencies and downloads the voice model. Windows may ask for installation permissions.

    If WinGet is unavailable, install Microsoft's App Installer and run the .bat again. If FFmpeg was just installed, you may need to reopen the .bat to refresh PATH.

    Microsoft WinGet ↗

  3. Start the web

    Use the same launcher next time. Completed dependencies and downloads are reused.

    Keep this terminal open while you use the app. Press Ctrl+C to stop the server.

macOS

Installer available

Voz Local does not have a macOS installer yet. The current installer uses AMD ROCm and cannot be used on a Mac.

  1. Download and extract the project

    Extract the whole project, including the scripts folder. The launcher cannot run by itself.

  2. Open the Mac launcher

    Instalar e iniciar.command

    It prepares Python 3.12 and installs FFmpeg with Homebrew, installing Homebrew from its official source if missing. It then prepares the dependencies and voice model. If the .command does not open, run the following in a terminal inside the project folder:

    bash instalar-e-iniciar.sh

  3. Start the web

    Use the same launcher next time. Completed dependencies and downloads are reused.

    Keep this terminal open while you use the app. Press Ctrl+C to stop the server.

Common questions

Do I need Ollama?

No. Qwen3-TTS generates the voice directly. Install Ollama only if you want help editing scripts.

Optional: download Ollama ↗
Do I need internet every time?

Internet is needed to install dependencies and download each model the first time. Once downloaded, voice generation is local. Selecting a model you do not have may trigger a download.

Why does the web not open?

The server must be running on the same computer as the browser. A localhost link alone does not install or start Voz Local. On this Ubuntu setup, run bash iniciar.sh again after restarting the computer.

Will everything install automatically?

The current Linux script installs the project environment and the 1.7B voice model. It requires FFmpeg and Python environment tools beforehand, and does not install system GPU drivers. Automatic Windows and macOS installers still need to be built.
